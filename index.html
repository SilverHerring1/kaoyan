UP · 向上 / 彻底完成 / 出现堆积

use up（用光）、turn up（出现）、make up for（弥补）、live up to（不辜负/达到高标准）。

OUT · 向外 / 耗尽 / 暴露产出 / 排除

turn out（结果证明为）、rule out（排除）、phase out（逐步淘汰）、bear out（证实）。

OFF · 脱离 / 中断取消 / 清偿消退

call off（取消）、put off（推迟/劝退）、pay off（见效/还清）、wear off（消退）、level off（趋平）。

DOWN · 压低 / 削减 / 崩塌 / 归结

turn down（拒绝/调低）、break down（分解/故障）、boil down to（归结为）。

OVER · 跨越 / 接管覆盖 / 掩饰翻转

get over（克服）、take over（接管）、gloss over（掩饰/轻描淡写）。

THROUGH / BACK · 穿透完成 / 阻滞回退

see through（看穿/坚持到底）、hold back（阻碍/隐瞒）、set back（使受挫）、cut back on（削减）。
