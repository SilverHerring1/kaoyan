```powershell
# 启动本地静态服务（切勿直接双击 file:// 打开，否则 fetch 会被拦截）
python -m http.server 8000
```

浏览器访问 `http://localhost:8000`（可直接通过 `#english`、`#control`、`#math1` 跳转对应科目）。

### 自动化质检命令

```powershell
# 1. 英语词库与外刊题硬校验
python scripts/validate_data.py

# 2. 理工科数据出处与 LaTeX 语法硬校验

# 3. 理工科公式与例题 SymPy 符号验算（工作区 .venv）

.\.venv\Scripts\python.exe scripts/verify_math1.py
```

## 部署到 GitHub Pages（纯分支部署）

1. 本仓库根目录包含 `.nojekyll` 且不启用冗余 Actions 工作流，避免与分支部署冲突。
2. 在工作区验证通过后，运行 `python scripts/sync_to_github_repo.py` 将洁净文件同步到 `D:\Documents\GitHub\kaoyan`（自动排除 `.env`、`data/raw/`、`.venv/`、`tmp/`、`status.md`）。
3. 在 **GitHub Desktop** 检查变更并 Commit & Push 到 `main` 分支，GitHub Pages 自动从 `main / (root)` 构建发布。
