# 考研三科冲刺工作台（英语一 · 845 自动控制原理 · 考研数学一）

面向考研冲刺阶段的纯静态 Web 学习工作台，零后端、零构建依赖，配合 **GitHub Desktop + GitHub Pages 纯分支部署（`main / root` + `.nojekyll`）** 即可一键发布。

## 三大科目分区

### 1. 考研英语一（11 个精编模块 · 625 条词目 · 27 道同源外刊题）
- **核心刷题词库（7 模块 · 470 条）**：高频非字面词组（含小品词空间隐喻速查）、熟词生义、易混形近词、完形近义词辨析、高频固定搭配与介词、逻辑词与完形、阅读同义替换；支持逐词点读、防剧透遮罩自测、随机洗牌与直达外刊原句单选。
- **纯记忆速背区（4 模块 · 155 条）**：态度题核心词 / 必错词（附作者 vs 第三方避坑铁律）、英一抽象学术名词、英一 7 大作文主题词与考场例句一键复制。

## 部署到 GitHub Pages（纯分支部署）

1. 本仓库根目录包含 `.nojekyll` 且不启用冗余 Actions 工作流，避免与分支部署冲突。
2. 在工作区验证通过后，运行 `python scripts/sync_to_github_repo.py` 将洁净文件同步到 `D:\Documents\GitHub\kaoyan`（自动排除 `.env`、`data/raw/`、`.venv/`、`tmp/`、`status.md`）。
3. 在 **GitHub Desktop** 检查变更并 Commit & Push 到 `main` 分支，GitHub Pages 自动从 `main / (root)` 构建发布。
