## 部署到 GitHub Pages（纯分支部署）

1. 本仓库根目录包含 `.nojekyll` 且不启用冗余 Actions 工作流，避免与分支部署冲突。
2. 在工作区验证通过后，运行 `python scripts/sync_to_github_repo.py` 将洁净文件同步到 `D:\Documents\GitHub\kaoyan`（自动排除 `.env`、`data/raw/`、`.venv/`、`tmp/`、`status.md`）。
3. 在 **GitHub Desktop** 检查变更并 Commit & Push 到 `main` 分支，GitHub Pages 自动从 `main / (root)` 构建发布。
