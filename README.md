## 为什么做「研习台」

考研冲刺阶段最消耗精力的，往往不是知识本身，而是**在厚教材、辅导书、真题卷、勘误表和生词本之间反复翻找**。研习台把三门核心科目装进同一个极简、可交互的纯静态网页里：

- **拒绝题海堆砌，只保留高密度精华**：每条公式、结论、例题与真题均标注**精确原书印刷页码与题号**，方便随时核对原书。
- **拒绝盲信错误答案**：自控与数一全部核心推导均经过 **SymPy 符号与数值验算**，已实锤捕获并透明双注 **230+ 处** 原教材、辅导书及真题答案册印刷错误或推导漏洞。
- **专注阅读，零打扰**：采用轻盈毛玻璃单行导航与柔和暖纸底色，所有学习进度与收藏均存在浏览器本地，无需注册、零追踪、离线也能用。

## 本地运行与自部署

本项目为**纯静态站点**，无需 Node 构建或数据库。切勿直接双击 `index.html`（浏览器的 `file://` 协议会拦截 `fetch`），请在项目根目录启动任意静态服务器：

```bash
git clone https://github.com/SilverHerring1/kaoyan.git
cd kaoyan
python -m http.server 8000
```

随后在浏览器打开 `http://localhost:8000` 即可使用。若需部署自己的在线版，Fork 仓库后在 **Settings → Pages** 中将 Source 设为 **Deploy from a branch → `main / (root)`**（根目录已内置 `.nojekyll`）即可零配置上线。

## 数据质检与校验

仓库内置完整自动化质检脚本，确保每处 LaTeX 公式、原书引用与数学推导真实准确：

```bash
# 1. 校验英语词库与外刊题结构
python scripts/validate_data.py

# 2. 校验自控与数一 JSON 引用溯源与 LaTeX 语法
python scripts/validate_stem.py

# 3. 运行 SymPy 符号与数值验算（需安装 sympy）
python scripts/verify_stem_math.py   # 845 自控：182 / 182 PASS
python scripts/verify_math1.py       # 考研数一：134 / 134 PASS
```
